# 저작권 지키기

> 이 스킬은 법률 자문이 아니다. 애매하면 선생님께 한국저작권위원회(상담 1800-5455) 문의를 권한다.

## 근거 (저작권법 제25조, 2024.8.28. 시행 기준)
- ③ 학교는 **수업 목적**으로 공표된 저작물의 **일부분**을 복제·배포·공중송신할 수 있다(부득이하면 전부).
- ⑤ 학생도 수업 목적상 필요하면 그 범위 안에서 복제·공중송신할 수 있다.
- ⑥ 보상금 — 고등학교 이하 학교의 복제 등은 보상금을 지급하지 않는다.
- ⑫ 공중송신(인터넷으로 보내기)할 때는 권리 침해를 막는 **필요한 조치**를 해야 한다(시행령: 수업 듣는 사람만 접근하게 하는 조치, 복제 방지 조치, 저작권 보호 경고 문구 등).
- '수업'에는 정규 교과, 방과후, 보충, 원격 수업이 포함된다. **우리 반 학생에게만**. 다른 교사·일반 공개·블로그·카페 공유는 허락이 필요하다.
- 출처 표시(제37조).

## 이 앱이 하는 것 (지우거나 끄지 않는다)
| 조치 | 어디서 |
|---|---|
| 접근 제한 — 구글 로그인 + 명단(members)에 있는 학생·선생님만 교과서 내용을 읽음 | `firestore.rules` (courses/** 읽기 조건) |
| 교과서 내용은 공개 호스팅에 올리지 않음 — content 폴더는 배포 대상이 아니고 Firestore로만 | `firebase.json`(public = app), 설정 › 교과서 올리기 |
| 검색 엔진 차단 | `robots.txt`, `X-Robots-Tag: noindex` 헤더 |
| 복제 방지(기본) — 쪽 그림 저장·끌기·오른쪽 클릭·인쇄 막기 | `book.js`, `book.css` |
| 경고 문구 + 출처 — 원본 보기·목차·다시 보기 하단 | `DT.credit()` ← `meta.source` |
| 체험(demo) 모드는 그 기기 브라우저 안에서만 | `data.js` |

복제 방지는 완벽할 수 없다(화면 촬영 등). 그래서 경고 문구와 접근 제한을 함께 둔다.

## 만들 때 규칙
1. **필요한 범위만** — 이번 학기에 가르치는 단원부터. 책 전체를 한꺼번에 만들어 두지 않는다(선생님이 원하면 "수업할 단원부터 만들고 이어서 추가"를 제안).
2. **암호·복사 금지 PDF는 열지 않는다** — `extract.py`가 멈춘다. 다른 도구·온라인 변환·화면 캡처 반복으로 돌아가지 않는다(기술적 보호조치 무력화 금지, 제104조의2). 선생님께:
   > "이 PDF에는 복사 금지 보호가 걸려 있어서 제가 내용을 꺼낼 수 없어요. 출판사 교사 지원 사이트에서 보호 없는 교사용 PDF를 받거나, 출판사에 수업용 이용을 문의해 주세요. 받으시면 바로 이어서 만들게요."
3. **meta.source**에 출판사·교과서 이름·연도를 정확히. 화면 하단에 출처로 나온다.
4. **교과서 밖 자료**: 교과서에 실린 작품·사진·지도·악보는 교과서에 실린 범위만. 같은 작품의 전문·고화질 원본을 따로 찾아 넣지 않는다. 음원·영상은 넣지 않는다(선생님이 정식 경로로 재생).
5. **3D·텍스처**는 직접 만들거나 CC0·퍼블릭 도메인·공공누리만 + `CREDITS.md` (`lab-3d` §5).
6. **글꼴**: 엔진 글꼴(Jua, SUIT)은 OFL — 함께 들어 있는 라이선스 파일을 지우지 않는다. 새 글꼴은 OFL 등 학교 사용이 허용된 것만.
7. 앱을 **다른 교사와 공유**하자는 요청: 엔진(코드)은 공유해도 되지만, 교과서 내용(content)이 든 앱·링크는 공유하지 않는다고 안내한다. 같은 교과서를 쓰는 다른 선생님은 자기 PDF로 자기 앱을 만들게 돕는다(`README.md`의 시작 방법).
8. 교과서 내용이 든 파일(content.js, 쪽 그림)을 GitHub·Netlify·공개 드라이브 링크에 올리지 않는다.

## 배포 전 확인 (privacy-guard와 함께)
- [ ] `firestore.rules`에 선생님 계정이 들어갔고(`__TEACHERS__` 없음), courses 읽기가 명단 조건인가
- [ ] `app/` 안에 content.js·pages 폴더가 없는가 (`firebase.json` public이 app인지)
- [ ] 학생 링크가 로그인 없이 교과서를 보여 주지 않는가 (시크릿 창으로 확인)
- [ ] 원본 보기·목차 하단에 출처와 경고 문구가 보이는가
