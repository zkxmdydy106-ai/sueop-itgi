# content.js 쓰는 법

파일: `작업물/<이름>/content/content.js` — `window.TEXTBOOK = { … };` (안은 **엄격한 JSON**: 큰따옴표, 끝 쉼표 없음, 주석 없음).
파이썬으로 고칠 때는 `tools/ingest/common.py`의 `load_content`/`save_content`를 쓴다. 다 쓰면 `python tools/verify/check_content.py 작업물/<이름>`.
완성된 예: `engine/demo-content/content.js` (가상 소단원 '정사영', 화면 10장).

## 전체 모양

```json
{
  "meta": { "title": "기하", "subject": "수학", "course": "기하", "publisher": "○○출판", "curriculum": "2022 개정",
            "source": "○○출판 『기하』(2025) — 수업 목적 이용" },
  "pages": { "pattern": "pages/p{n}.webp", "hi": "pages/hi/p{n}.webp", "pad": 3, "from": 62, "to": 120, "ratio": 1.31, "pairing": "even-left" },
  "units": [ { "id": "u2", "no": "Ⅱ", "title": "공간도형과 공간좌표", "children": [
      { "id": "u2-1", "no": "1", "title": "공간도형", "children": [
          { "id": "u2-1-3", "no": "03", "title": "정사영", "pages": [72, 76],
            "standards": [ { "code": "[12기하02-03]", "text": "…(성취기준 문장 그대로)…", "can": "정사영의 뜻을 설명할 수 있어요" } ],
            "keywords": ["정사영", "수선의 발"],
            "explore": [ … ], "practice": [ … ],
            "screens": [ … ] } ] } ] } ],
  "glossary": [ … ], "hotspots": { … },
  "lines": { … }, "terms": { … }        ← attach_index.py가 채움 (손대지 않는다)
}
```
- 단원 깊이는 자유(대 > 중 > 소). **`screens`가 있는 마디가 소단원**이다. 소단원 `pages`는 [시작쪽, 끝쪽].
- `meta.source`는 출처 표시로 화면에 나온다 — 출판사·교과서 이름·연도.
- `standards.code`는 2022 개정 교육과정의 **실제 성취기준 코드와 문장**. 모르면 웹 검색(교육부 고시·NCIC)으로 확인. 못 찾으면 `"code": "[확인 필요]"`로 두고 BRIEF에 적는다. 지어내지 않는다. `can`은 학생 말투 자기평가 문장.

## 화면 (screen)

```json
{ "id": "u2-1-3.s4", "kind": "concept", "step": "STEP 3 · 정사영의 길이", "chip": "정사영의 길이",
  "title": "정사영의 길이", "lead": "(선택) 제목 아래 한 줄", "pages": [74], "blocks": [ … ] }
```
| 칸 | 뜻 |
|---|---|
| id | `소단원id.s번호` — 한 번 정하면 바꾸지 않는다(판서·기록이 이 id에 붙는다). 사이에 넣을 땐 `s4b` |
| kind | `open`(생각 열기) `concept`(개념) `problem`(예제·문제) `activity`(탐구·활동) `summary`(정리) |
| step | 교과서의 단계 이름 그대로 (교과서에 없으면 'STEP n · 소제목') |
| chip | 아래 진행 막대에 보이는 짧은 이름 (8자 안팎) |
| pages | 이 화면 글이 있는 **교과서 쪽**. '교과서 n쪽' 버튼이 이 쪽을 연다 — 정확해야 한다 |

### 화면 나누기 기준 (스크롤 없음)
- 칠판 화면은 1920×1080, 글자 기본 30px대. 5m 뒤에서 읽혀야 한다.
- 한 화면 = 선생님이 **한 번에 설명하는 분량**: 정의 1개 + 그림 1개, 또는 예제 1개 + 문제 1개, 또는 탐구 하나.
- 교과서 한 쪽이 보통 화면 1~3장. 글이 많은 쪽(사회·국어)은 문단 단위로 나눈다. 문장 중간에서 끊지 않는다.
- 그림이 있는 개념은 `cols`로 글 | 그림 2단 (`ratio` [5,4] 정도).
- `audit_app.py`가 글자를 줄여도 넘친다고 하면(✗) **화면을 나눈다.** 글을 줄이거나 요약하는 것은 해결이 아니다.
- 단계 열기 `r`: 칠판에서 '다음'을 누를 때 차례로 보일 블록에 1, 2, 3… (같은 숫자는 함께). 발문 → 답, 정의 → 참고처럼 수업 흐름이 있을 때만. 모든 블록에 붙이지 않는다.

## 블록

모든 글 칸(`x`, `q`, `items` …)은 아래 **표기법**을 쓴다.

| t | 칸 | 쓰는 곳 |
|---|---|---|
| `p` | x | 본문 문단 |
| `h` | x | 화면 안 소제목 |
| `def` | x, label('정의'·'성질'·'개념 노트'), kind('law'=강조) | 정의·성질·공식 상자 (교과서의 개념 노트) |
| `note` | x, label('참고'·'보기'·'주의') | 참고·보기·도움말 |
| `list` | items[], ordered | 목록 |
| `table` | head[], rows[[]] | 표 (칸 수 같게) |
| `fig` | src 또는 svg, cap, alt, w('70%'), align | 그림. 교과서 그림은 `figs/…webp`, 직접 그린 그림은 svg |
| `ex` | label('예제 1'), page, q, sol[](단계), ans, solLabel('증명' — 교과서 풀이 칸 이름이 다를 때) | 예제 — 칠판에서 풀이를 한 단계씩 연다 |
| `prob` | label('문제 1'), page, q, sub[], ans, sol[], grade | 문제 — 누르면 크게 열려 판서. grade가 있으면 학습지 자동 채점 |
| `act` | label('탐구'·'함께 해 보기'), title, x, items[], group(true=모둠) | 탐구·활동 — 모둠이면 모둠 활동지·동료평가가 생긴다 |
| `read` | label('읽기 자료'), title, x, items[] | 읽기 자료·생활 속 이야기 |
| `lab` | lab, label, desc, props{}, theme{}, title, fig | 3D·실험 모형 버튼 (`lab-3d`) |
| `viz` | kind + 종류별 칸, title, stepwise | 글로만 된 개념을 그림으로 (`lab-3d` §viz) |
| `cols` | ratio[], cols[[블록…],[블록…]] | 2~3단 배치 |
| `html` | html | 쓰지 않는다 (마지막 수단) |

### 문제 채점 키 `grade`
```json
{ "type": "num",    "key": "4√3|4\\sqrt3|4\\sqrt{3}" }          // 숫자: 값으로 비교 (분수·√·π 허용). 다른 표기는 | 로
{ "type": "text",   "key": "30°|30|30도" }                       // 글: 띄어쓰기·문장부호 무시하고 비교
{ "type": "choice", "key": "3", "choices": ["…", "…", "…", "…", "…"] }   // 객관식: key는 번호(③ → "3", 1부터). choices에는 ①② 없이 보기 글만 (화면이 붙인다)
{ "type": "ox",     "key": "O" }
// 소문항이 있으면 key를 배열로: "sub": ["(1) …", "(2) …"], "grade": { "type": "num", "key": ["5", "12"] }
```
- 정답은 **교과서 정답(교사용 해설)과 대조**한다. 확인 못 한 문제는 grade를 빼고 `ans`만 → 학습지에서 서술형(사진·필기)으로 나간다.
- 증명·서술·그리기 문제는 grade 없이 `ans`(예시 답)·`sol`.

### 표기법 (글 칸 안)
| 쓰기 | 결과 |
|---|---|
| `$\overline{\mathrm{AB}}\cos\theta$` | 수식(KaTeX). 한 줄 안에서 닫는다 |
| `$$S'=S\cos\theta$$` | 가운데 큰 수식 |
| `[[정사영]]` | 핵심어 — 굵게 + **빈칸 학습지의 빈칸** + 용어 뜻 연결. 교과서에서 굵게·색으로 강조된 말에만. 수식 안에는 쓰지 않는다 |
| `**굵게**` `==형광==` `__밑줄__` | 교과서에 그 강조가 있을 때만 |
| 줄바꿈 `\n` | 줄 나눔 |

## 소단원에 붙는 것

```json
"explore": [ { "fields": ["공학·기술", "자연과학"], "page": 76, "from": "함께 탐구 · 그림자 넓이 실험",
               "idea": "태양광 패널의 기울기에 따라 받는 햇빛의 양을 cosθ로 설명하기",
               "q": "우리 지역의 계절별 태양 고도에서 패널을 몇 도 기울여야 할까?" } ],
"practice": [ { "q": "…", "key": "3", "mode": "num", "page": 74, "screen": "u2-1-3.s4", "sol": ["…"] } ]
```
- `explore` = 진로 탐구 추천(교과서 속 탐구·읽기 자료·예시에서 출발). 2~4개, 서로 다른 진로 분야. 분야 이름은 이 9개 중에서: 공학·기술, 자연과학, 의약·보건, IT·인공지능, 경영·경제, 인문·사회, 교육, 예술·디자인, 체육·스포츠. 학생은 이 추천을 고르거나 자기 생각을 쓴다.
- `practice` = 교과서 문제 외에 학습지에 더 넣을 문제(교과서의 '스스로 확인'·'단원 마무리' 등 **교과서에 있는 문제**). 새로 지어낸 문제는 넣지 않는다(넣으려면 선생님께 묻고 `label: "선생님 문제"`).
- `variants` = **변형 문제**(선생님이 원할 때만): 교과서 개념별로 숫자·조건을 바꾼 새 문제. `{concept, q, type, mode, key, choices?, sol}`. 정답은 **코드로 계산**해 넣는다(손으로 적지 않음) — 예: `작업물/기하_지학사/content/_extract/make_variants.py`. 학습지·인쇄에서 항상 「변형」으로 표시돼 교과서 글과 섞이지 않는다. 개념마다 4~6개.

## 용어 (glossary)

```json
{ "term": "정사영", "def": "점 P에서 평면 α에 내린 수선의 발 P′을 점 P의 평면 α 위로의 정사영이라고 한다.", "page": 72, "screen": "u2-1-3.s2" }
```
- 뜻은 **교과서 문장 그대로**. 교과서에 없는 말(이전 학년 용어)은 이전 교과서 표현에 가깝게 짧게 쓰고 `"src": "보충"`.
- `page`·`screen`은 처음 나오는 곳 — 원본 보기에서 "n쪽으로 가기", 칠판에서 "그 화면으로 가기"에 쓰인다.
- 소단원의 `[[핵심어]]`는 모두 glossary에 있어야 한다.

## 원본 위 3D 버튼 (hotspots)

```json
"hotspots": { "74": [ { "x": 0.06, "y": 0.4, "w": 0.6, "h": 0.12, "lab": "projection", "label": "3D로 보기",
                        "title": "정사영의 길이", "props": { "mode": "segment", "angle": 30 }, "theme": { … } } ] }
```
쪽 번호(문자열 키) → 그 쪽 위 사각형(0~1 비율). 자리는 `_extract/pages.json`의 그림 후보 box를 쓴다.

## 자주 하는 실수
- 교과서 문장을 매끄럽게 '다듬기' → 금지. 원문 그대로(맞춤법 포함).
- 문제 번호·쪽수 빠뜨림 → `label`, `page` 필수.
- 화면 id 바꾸기 → 판서·기록이 끊긴다.
- `$` 안에 한글 → `\text{…}`로.
- 그림을 svg로 다시 그릴 때 교과서와 다른 색·다른 기호 → 교과서 그림과 같은 색·기호(점 이름, 각 표시)로.
