# 과목에 맞게 설계하기

엔진은 하나지만 과목마다 수업의 '모양'이 다르다. 교과서 글은 그대로 두고, **화면 나누기·단계 열기·시각화·학습지 거리**를 과목에 맞춘다.
모든 과목 공통: 교과서의 흐름(도입 → 전개 → 정리)과 교과서가 붙인 이름(생각 열기, 탐구, 개념 노트, 스스로 확인 …)을 그대로 쓴다.

## 시각화 판단 (모든 과목)

소단원의 개념마다 묻는다: **"학생이 머릿속으로 그려야 하는데, 정지 그림이나 글로는 잘 안 그려지는 것이 있나?"**
- 공간·입체·움직임·변화·비율·원인과 결과·과정·비교 → 시각화 후보
- 교과서에 그림이 있다 → 그 그림을 **움직이게/돌려 보게** (같은 색·같은 기호)
- 그림이 없다 → 글의 구조(순서, 순환, 비교, 포함 관계, 시간)를 `viz`로, 공간·물리 현상이면 3D로
- 단순 사실·정의만 있는 화면에는 억지로 만들지 않는다 (난잡해진다)
→ 만들 것은 BRIEF '시각화 계획'에 먼저 적고, 방법은 `lab-3d`.

## 과목별

### 수학
- 화면: 정의(def) → 성질(def kind law) → 예제(ex, 풀이 단계) → 문제(prob) 순. 예제 하나 + 대응 문제 하나가 한 화면이 보통.
- 단계 열기: 발문 → 답, 성질 유도 과정.
- 시각화: 입체·공간(정사영, 공간좌표, 회전체) → 3D. 함수·그래프 매개변수 → `viz graph` (조절 막대). 수열·급수·극한 → 단계별 viz 또는 간단 lab. 통계·확률 → 시뮬레이션 lab(주사위·표본 추출).
- 채점: 대부분 `num`. 증명·서술은 grade 없이(판서 제출).
- 진로: 공학·IT·경영·자연과학 위주이되 교과서 '수학 이야기·생활 속 수학'에서 출발.

### 과학 (물리·화학·생명·지구)
- 화면: 탐구 질문 → 실험(act, 준비물·과정 items) → 결과 해석 → 개념. 실험은 교과서 순서 그대로.
- 시각화: 실험을 대신하거나 보이지 않는 것을 보이게 — 분자 운동(기체 법칙), 힘·운동 궤적, 전기·자기장, 세포·기관 구조(3D), 판 구조·지층·천체 운동, 화학 결합·분자 모양(3D). 측정값이 나오는 모형은 그래프를 같이(가스 모형의 P-V 그래프처럼).
- 안전: 실제 실험 안전 수칙은 교과서 글 그대로 화면에.
- 채점: 계산 `num`, 개념 `choice`/`ox`, 해석은 서술.

### 사회 (지리·역사·일반사회·윤리)
- 화면: 글이 많다 → 문단 단위로 나누고, 자료(지도·사진·표·그래프)는 크게 한 화면에. 자료 읽기 발문은 단계 열기.
- 시각화: 지형·기후 → 3D 지형(등고선·단면, terrain 모형). 이동·확산 → 지도 위 경로. 역사 → `viz timeline`, 인과 → `viz flow`. 제도·개념 비교 → `viz compare`/`venn`. 통계 자료 → 표를 그래프로(원자료는 교과서 표 그대로 함께).
- 지도는 교과서 지도를 그대로 쓰거나(fig) 공공 자료(국토지리정보원, Natural Earth — 공공누리/퍼블릭 도메인)로. 국경·지명은 교과서 표기를 따른다.
- 채점: 용어 `text`, 자료 해석 `choice`. 논술·토론은 모둠 활동지.

### 국어
- 화면: 제재(작품) 글은 **교과서에 실린 범위 그대로** 문단·연 단위로. 학습 활동은 act.
- 저작권 주의: 문학 작품은 교과서에 실린 부분만. 작품 전문을 따로 찾아 넣지 않는다.
- 시각화: 서사 구조·인물 관계 → `viz map`/`flow`, 시점·관점 비교 → `compare`. 3D는 거의 쓰지 않는다.
- 학습지: 빈칸보다 서술(내 생각 쓰기)·모둠 토의 중심. 문법은 `choice`/`ox`.

### 영어
- 읽어 주기 켜짐(브라우저 en-US 음성 — 학교 기기 음성 품질은 사용자 점검).
- 화면: Reading 본문은 문단 단위, 어휘(glossary: 뜻은 교과서 Words 표현), Listening 대본은 교과서에 실린 것만.
- 시각화: 이야기 순서 `flow`, 비교 `compare`. 문법 패턴은 표.
- 채점: 어휘·문법 `text`(대소문자·띄어쓰기 무시), 순서 배열 `choice`.

### 정보
- 화면: 개념 → 예시 코드(표 또는 html 블록 대신 `note`에 코드) → 실습(act).
- 시각화: 알고리즘 단계(정렬·탐색) → 단계별 lab 또는 `viz flow`, 자료 구조 → 그림, 네트워크 → `map`. 인공지능(분류·군집) → 산점도 lab.
- 채점: 출력값 `text`, 개념 `choice`.

### 기술·가정, 보건
- 화면: 생활 사례 → 원리 → 실천. 안전·건강 정보는 교과서 글 그대로(바꾸면 위험할 수 있다).
- 시각화: 인체 구조·기관(3D, 사실적인 재질 — 단 과도하게 생생한 해부 표현은 피하고 교과서 그림 톤), 응급 처치 순서 → `flow`, 영양·식단 비교 → `compare`, 기계·구조물 원리 → 3D.
- 학습지: 자기 생활 점검(자기평가형)과 실천 계획.

### 체육
- 화면: 동작·전술 설명이 핵심. 교과서 사진·그림을 크게.
- 시각화: 동작 순서 → `flow`(단계 열기), 전술·대형 → 코트·경기장 위 위치 이동 lab(위에서 본 2.5D), 체력 요소 비교 → `compare`.
- 학습지: 실기 자기평가·동료평가(모둠), 운동 계획.

### 음악·미술
- 화면: 작품·악보는 교과서에 실린 그림 그대로 크게(fig). 감상 발문은 단계 열기.
- 저작권 주의: 교과서에 실린 작품 이미지·악보만. 음원은 넣지 않는다(교과서 출판사 제공 음원이 있으면 선생님이 따로 재생).
- 시각화: 시대·사조 `timeline`, 요소 비교 `compare`, 미술의 원근·구도 → 3D(소실점 장면), 음악 요소(음높이·리듬) → 간단한 그래프 lab.
- 학습지: 감상문(서술), 표현 계획, 동료평가.

### 제2외국어·한문
- 영어와 같되 읽어 주기는 꺼져 있다(영어만). 한자·문자 표는 table.

## 교수·학습·평가·기록 연결 (모든 과목)

소단원 하나마다 이 고리가 끊기지 않게 만든다 (`pedagogy-reviewer`가 점검):
1. **성취기준** (standards) — 실제 코드와 문장, 학생 말투 `can`
2. **가르치는 화면** — 성취기준의 각 부분이 어느 화면에서 다뤄지는지
3. **확인하는 문항** — 그 화면의 문제(grade)·핵심어([[ ]])가 학습지로 나간다
4. **기록** — 제출 → 정답률·개념별 → 생기부 근거 문장의 재료(관찰 기록, 자기평가, 진로 탐구)
- 성취기준 하나에 확인 문항이 하나도 없으면 교과서의 문제·탐구에서 찾아 grade를 단다(새 문제를 지어내지 않는다).
- 진로 탐구(explore)는 교과서 안의 탐구·읽기 자료·사례에서 출발해야 생기부 근거로 쓸 수 있다.
