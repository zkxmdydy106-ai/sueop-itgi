## 실행 플랫폼별 주의
- **Apps Script(GAS)**: iframe 안에서 열림 → `school-webapp` 스킬 §2 표를 따른다.
- **Netlify / GitHub Pages / 단일 HTML 파일**: 상대 경로, 캐시. 개인정보를 정적 파일에 넣지 않는다.
- **학교망**: 일부 CDN·Google Fonts가 막히는 학교가 있다 → 대체 글꼴 스택으로도 보기 좋게, 핵심 기능은 외부 자원 없이 동작.
- **크롬북/웨일**: 웨일 브라우저도 크로미움 기반이라 크롬 기준으로 대부분 맞지만, 실제 확인 못 했으면 밝힌다.
