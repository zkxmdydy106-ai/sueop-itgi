# 'AI가 만든 티' 목록 — 전달 전 대조

표시: 🔧 = `.claude/hooks/design_lint.py`가 자동으로 찾아 경고함 / 👁 = 눈(스크린샷)으로 확인.
하나라도 해당하면 고친다. 예외는 BRIEF.md에 "의도적으로 사용: 이유"가 적혀 있을 때뿐.

## 색·표면
- 🔧 보라↔파랑/분홍 그라데이션 (`#667eea → #764ba2` 류, `from-purple-500 to-blue-500`)
- 🔧 배경 유리 효과 `backdrop-filter: blur` 남용
- 🔧 모든 카드에 같은 `box-shadow: 0 4px 6px rgba(0,0,0,.1)` 류의 회색 그림자
- 🔧 Claude 고유 주황 `#D97757`, 크림 배경 `#F4F1EA` 조합
- 👁 장식용 그라데이션 블롭·빛 번짐 배경
- 👁 어두운 배경에 형광 초록/주황 포인트 하나 (주제와 관계없이)
- 👁 의미 없는 색 남발 — 카드마다 다른 파스텔

## 글자
- 🔧 글꼴 지정이 Inter/Roboto/Arial/system-ui뿐 (한글 글꼴 선택 없음)
- 🔧 작은 라벨을 `text-transform: uppercase` + 넓은 자간으로 (한글에는 의미도 없음)
- 🔧 제목·버튼에 이모지 (🎯✨🚀📊💡🔥👋✅)
- 🔧 버튼·링크 끝에 `→` 붙이기
- 👁 제목에서 한 단어만 색/기울임으로 강조
- 👁 모든 섹션 제목 위에 작은 꼬리표(eyebrow) 라벨
- 👁 'A · B · C' 가운뎃점 메타 문자열 남발
- 👁 작은 데이터 라벨에 고정폭(monospace) 글꼴
- 👁 한글 단어가 중간에서 줄바꿈됨 (`keep-all` 누락)

## 배치
- 👁 아이콘 + 제목 + 설명 카드 3개(또는 4개)가 나란히 — 내용이 원래 그런 구조가 아닌데
- 👁 업무 도구인데 히어로(큰 제목 + 부제 + 버튼 두 개)로 시작
- 👁 모든 것을 가운데 정렬
- 👁 모든 상자의 모서리 반경이 같음 (계층과 무관하게 `rounded-xl`)
- 👁 카드 안에 카드 안에 카드
- 👁 01 / 02 / 03 번호 — 순서가 있는 내용이 아닌데
- 👁 "통계 숫자 크게 + 작은 라벨" 3개 나란히 (근거 없는 숫자면 더 나쁨)

## 움직임
- 🔧 모든 요소에 `transition: all`
- 👁 섹션마다 아래에서 올라오며 나타나는 효과
- 👁 모든 카드 hover 시 떠오름(translateY) + 그림자 증가
- 👁 이유 없는 무한 반복 애니메이션 (반짝임, 둥둥)

## 문구
- 🔧 "환영합니다!", "스마트한", "손쉽게", "한눈에", "AI 기반", "혁신적인", "최고의 경험"
- 👁 느낌표 남발, 과장된 친근함 ("짜잔!", "멋져요!")
- 👁 기능 설명 대신 홍보 문구
- 👁 Lorem ipsum, "홍길동"·"OO고등학교" 같은 가짜 데이터가 최종본에 남음 → 실제 같은 예시 데이터(학번 20315, 2학년 3반, 실제 교시 시각)로
- 👁 버튼 이름이 "제출", "확인", "클릭하세요"

## 아이콘·그림
- 👁 이모지를 아이콘 대신 사용
- 👁 아이콘 세트가 섞임 (선 굵기·스타일 불일치)
- 👁 주제와 무관한 일반 일러스트(사람들이 노트북 보는 그림)
- 👁 학교·과목·지역의 실제 소재(교실, 칠판, 교과 개념 도식, 시간표)가 하나도 없음

## 마감 부족 (전문가와의 차이)
- 👁 빈 상태·오류 상태·로딩 상태가 기본값 그대로
- 👁 긴 이름("김가나다라마바사")이나 300행 데이터에서 무너짐
- 👁 포커스 링 제거 (`outline: none`만 있고 대체 없음) ← 🔧
- 👁 인쇄하면 버튼·배경이 그대로 나오고 표가 쪽 사이에서 잘림
- 👁 390px에서 가로로 밀림
