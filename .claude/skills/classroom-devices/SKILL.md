# 교실 기기

## 화면 크기 기준
| 기기 | 크기 | 쓰는 화면 |
|---|---|---|
| 전자칠판(65~86인치) | 1920×1080 (4K도 같은 비율로 확대) | `board.html` — 1920×1080 무대를 화면에 맞춰 키운다 |
| 교사 PC | 1366×768 ~ 1920×1080 | `teacher.html` |
| 학생 아이패드 | 1180×820 가로 / 820×1180 세로 (10세대·Air) | `student.html` |
| 학생 휴대폰(예외) | 390×844 | `student.html` (작동은 하되 아이패드 우선) |

- 칠판 글자: 5m 뒤에서 읽히게. 본문 기본 30px대(무대 기준), 최소 22px. `audit_app.py`가 글자를 80% 아래로 줄인 화면을 △로 알린다.
- 스크롤 금지: 모든 화면이 한 장에. 학생 화면도 페이지 스크롤 0(목록은 쪽 넘김).
- 터치 목표: 칠판 버튼 64px 이상, 아이패드 44px 이상.

## 전자칠판
- 브라우저: 크롬 또는 웨일. 처음 한 번 전체 화면 버튼(오른쪽 위). 칠판 PC가 느리면 3D 모형이 저절로 화질을 낮춘다.
- 판서: 손가락·전용 펜 모두 '펜'. 지우개는 획 단위. 판서는 반·화면마다 저장(같은 PC 즉시 + Firebase).
- 키보드(무선 키보드·리모컨): ←/→ 넘기기, P 펜, H 손, E 지우개, L 레이저, Ctrl+Z 되돌리기, Esc 닫기.

## 애플펜슬 (교사·학생 아이패드)
엔진(`ink.js`)이 하는 것:
- 펜이 한 번이라도 닿으면 그 뒤로는 **손바닥·손가락 터치를 판서로 받지 않는다**(손을 화면에 대고 써도 됨).
- 필압: 펜을 세게 누르면 굵게(점마다 굵기 저장).
- 저장: 쓰고 1.2초 뒤 저장. 학생 필기는 그 학생 계정(`stu_…`)에만 — 다른 아이패드에서 로그인해도 그대로.
- 선생님 준비: 반을 고르지 않고(반 없이 보기) 아이패드에서 쓴 판서는 '준비(prep)' 판서 → 전자칠판에서 반을 고르고 그 화면을 열면, 그 반 판서가 비어 있을 때 준비 판서가 나타난다.

수업 전 점검(사용자 점검 목록에 그대로 쓴다):
1. 아이패드 Safari에서 학생 주소 열기 → 홈 화면에 추가(공유 › 홈 화면에 추가) — 주소창 없이 넓게.
2. 학습지 서술 문항에서 펜으로 써 보고, 손바닥을 대도 선이 안 생기는지.
3. 손글씨가 글자로 바뀌면: 설정 › Apple Pencil › '손글씨 입력(Scribble)' 끄기 (입력 칸에서만 해당, 판서 칸은 영향 없음).
4. 로그인 팝업이 막히면: 설정 › Safari › 팝업 차단 해제(엔진이 전체 화면 로그인으로 자동 전환하므로 보통 필요 없음).

## 학교 와이파이·방화벽
막히면 로그인·기록이 안 된다. 정보부에 열어 달라고 할 주소:
`*.googleapis.com`, `accounts.google.com`, `apis.google.com`, `www.gstatic.com`, `*.firebaseapp.com`, `*.web.app`
엔진 파일(글꼴·수식·3D)은 모두 앱 안에 들어 있어 외부 CDN이 필요 없다.

## 고칠 때 확인할 것
- 판서·포인터 코드를 고치면 마우스·터치·펜(pointerType) 세 경우를 모두 생각한다. 실제 펜은 여기서 시험할 수 없다 → 전달 때 "실제 애플펜슬 확인 필요"를 적는다.
- `touch-action: none`이 칠판·책·모형·판서 영역에 있어야 브라우저 확대·뒤로 가기 제스처가 끼어들지 않는다.
- iOS Safari: `100vh` 대신 엔진이 쓰는 `innerHeight` 기반 맞춤을 쓴다. 입력 칸 글자 16px 이상(작으면 자동 확대됨).
